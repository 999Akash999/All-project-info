# 🚀 Projects

## Public Projects

### Make Your Trip [https://make-your-trip-90sr.onrender.com/listings]

A full-stack travel booking platform developed using Node.js, Express.js, MongoDB, and EJS. The application allows users to explore destinations, manage listings, book stays, search flights and cabs, upload images, and securely authenticate using local login and Google OAuth. It includes Cloudinary integration for media storage and Mapbox integration for location-based features.

### AkashGPT  [https://akash-gpt-1.onrender.com/]

An AI-powered chatbot application built with React.js, Node.js, Express.js, and MongoDB. The platform supports real-time conversations, thread management, chat history storage, and seamless AI interaction through an intuitive and responsive user interface.

### Zerodha Clone [https://zerodha-clone-1-zjom.onrender.com/]

A modern stock trading platform inspired by Zerodha, developed using React.js and Node.js. The project replicates core trading dashboard functionalities, providing users with a clean interface for portfolio tracking, market insights, and trading-related workflows.
